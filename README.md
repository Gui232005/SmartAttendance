# Overview

SmartAttendance aims to record and manage attendance automatically, combining:
## Backend
Interface and/or web layer (mainly in JavaScript, with HTML/CSS) <br>
Integration with typical embedded system features (sensors, identification, hardware communication, etc.)<br>

## Features
User registration and identification <br>
Attendance recording with date/time <br>
Attendance check by user/time period <br>
Web dashboard for viewing and administration <br>
Integration with an embedded device for capture/validation <br>

## Technologies
JavaScript (application layer / interface / API) <br>
Python (automation, services, hardware integration, scripts) <br>
HTML/CSS (interface)
